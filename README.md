# Sound-Saver

A Python based YouTube > MP3 Downloader i created towards the beginning of my coding carrer. Designed the UI in Figma. Hope you find use for it, enjoy!

Simply copy the desired video link from the URL > Paste it in the "Video Link" text field > Click the "File" button & output path to save audio to > Click 'Save'. That easy.

Clone the repo here: https://github.com/Recoverrrr/Sound-Saver.git

The .exe version will appear as a virus due to Windows flagging .exes, if you dont want to run the .exe file simply run the python script included to get the same result. (.exe not supported on MAC OS)
